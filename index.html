🔌 Amazon画像・価格の自動取得（PA-API）をつなぐ手順
1. Amazonアソシエイト・プログラムに登録し、直近180日で3件以上の紹介実績を作る（PA-API利用申請の条件） 2. 審査後、Product Advertising API の利用申請を行い、アクセスキー・シークレットキーを発行 3. 下の「Workerコード」をコピーし、Cloudflare Workers（無料枠で可）に新規Workerとしてデプロイ 4. Worker の環境変数（Settings → Variables）に AMAZON_ACCESS_KEY / AMAZON_SECRET_KEY / AMAZON_PARTNER_TAG を設定 5. デプロイ後に発行される Worker のURLを、上の「PA-API連携Worker URL」欄に貼って保存 6. 以降、詳細ページを開くたびに商品画像・現在価格が自動取得されます（取得できない場合は自作アイコンのまま表示）
